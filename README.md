# Good-ometer

A simple, offline-friendly web app to measure the "goodness" of anything!

## Features

- Works completely offline
- No dependencies or build process required
- Measures the goodness of any text input
- Visual meter with animated results
- Saves measurement history locally
- Fun and simple to use

## Usage

Simply open `index.html` in any web browser. No server or installation needed!

1. Enter anything you want to measure
2. Click "Measure Goodness"
3. Watch the meter fill up
4. See your goodness score!

## How It Works

The good-ometer uses a simple algorithm that considers:
- Positive and negative words
- Text length and variety
- A bit of randomness for fun

All data is stored locally in your browser using localStorage.

## Offline-Friendly

This is a single HTML file with all CSS and JavaScript embedded. Perfect for:
- Offline use
- Quick demos
- Learning web development
- Having fun!
